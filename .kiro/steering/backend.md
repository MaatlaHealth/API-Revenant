# Backend Engineering Standards

- Routers validate input, call a service, and shape the response. Business logic lives in service modules.
- Pydantic models use `extra="forbid"` for request bodies. Response models are explicit; never return ORM objects.
- All I/O is `async`. No blocking calls in request handlers or the runtime path.
- Database access uses a session per request (or per unit of work in background tasks). State changes that belong together happen in one transaction.
- Errors: raise typed domain errors; one handler maps them to the common error envelope. Never swallow an exception silently; log with context and surface it.
- Runtime code path must not block on the database. Traces go through the bounded queue.
- Compiled adapters are immutable. Replace by reference; never mutate in place.
- Type hints everywhere; `mypy --strict` on `transform` and `security`.
- Migrations must run on both SQLite and PostgreSQL; review autogenerated migrations by hand.
- Log with `structlog`, key-value style, one event name per occurrence.
- Do not introduce module-level mutable state other than the runtime registry and the shared HTTP client, both owned by the app lifespan.
